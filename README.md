# Jack Brecker — Portfolio

Single-file site (`index.html`, no build step). Light/dark follows the visitor's system setting.

## Host free on GitHub Pages
1. Create a public repo (e.g. `jackbrecker.github.io` for a root URL, or any name).
2. Add `index.html` to the repo root and push.
3. Repo Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Every push to `main` redeploys automatically in about a minute.

Contact links to the GitHub profile; add an email or LinkedIn button in the Contact section if wanted.
